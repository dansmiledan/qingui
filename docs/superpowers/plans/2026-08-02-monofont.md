# 多位图字体支持(MonoFont)实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/superpowers/specs/2026-08-02-monofont-design.md` 把字体系统从 font8x8 单字号升级为 embedded-graphics `MonoFont`:多字号可选、用户可插 eg 生态字体、默认字体换 FONT_6X10。

**Architecture:** 经 `DrawTarget` 适配复用 e-g 的 Text 渲染器与 `measure_string`(不自写字模数学);`Style.font` 三级解析(overlay → base → Ui 默认);删除 font8x8 依赖。

**Tech Stack:** Rust no_std + alloc;`embedded-graphics = "0.8"`(default-features = false);host `cargo test -p qingui`;嵌入式 `cargo build -p qingui --target thumbv7em-none-eabihf`。

## Global Constraints

- no_std + alloc;draw 热路径无分配;文本背景保持透明(Off 像素不写)。
- 默认字体 `embedded_graphics::mono_font::ascii::FONT_6X10`;接受外观变化,受影响测试逐个更新预期(禁止放松断言为"能过就行")。
- 字体三级解析:overlay.font → base.font → Ui.default_font。
- pos 语义保持:文本左上角(Baseline::Top)。
- e-g API 细节(Text 构造/baseline/measure_string 路径)以 0.8 实际版本为准;像素测试钉住语义,出入记录在报告。
- 中文注释风格;commit message 中文;仅本地提交不 push。
- 每个 Task 结束:`cargo test -p qingui` 全绿 + thumbv7em + `cargo check -p qingui --examples`。

- [ ] **Step 2: 重写 qingui/src/font.rs**

```rust
//! 字体:embedded-graphics MonoFont 渲染与度量。
//! 经 DrawTarget 适配复用 e-g 的 Text 渲染器;Off 像素不写(背景透明)。

use embedded_graphics::mono_font::MonoFont;
use embedded_graphics::text::renderer::TextRenderer;

/// 默认字体(最接近原 font8x8 的紧凑度)
pub const DEFAULT_FONT: &MonoFont = &embedded_graphics::mono_font::ascii::FONT_6X10;

/// 逐字水平步进(字宽 + 字距)
pub fn advance(font: &'static MonoFont) -> i32 {
    (font.character_size.width + font.character_spacing) as i32
}

/// 行高
pub fn line_height(font: &'static MonoFont) -> i32 {
    font.character_size.height as i32
}

/// 文本尺寸(支持 '\n';经 e-g measure_string,语义与渲染严格一致)
pub fn text_size(font: &'static MonoFont, s: &str) -> (i32, i32) {
    let style = embedded_graphics::mono_font::MonoTextStyle::new(font, embedded_graphics::pixelcolor::BinaryColor::On);
    let m = style.measure_string(s, embedded_graphics::geometry::Point::zero(), embedded_graphics::text::Baseline::Top);
    (m.bounding_box.size.width as i32, m.bounding_box.size.height as i32)
}
```

注:measure_string 对空串/尾随换行的 bounding box 语义以 0.8 实际行为为准,测试钉住;若空串高度为 0 而旧语义是 LINE_H,在 text_size 内特判 `s.is_empty() → (0, line_height(font))`。

- [ ] **Step 3: draw.rs 的 draw_text(_opa) 重写**

`DrawBuf` 增加:

```rust
    /// 经 e-g Text 渲染器绘制文本;On 像素走 put(fg/opa),Off 不写(背景透明)。
    pub fn draw_text(&mut self, pos: crate::geometry::Point, font: &'static embedded_graphics::mono_font::MonoFont, s: &str, c: Color, clip: Rect) {
        self.draw_text_opa(pos, font, s, c, 255, clip);
    }

    pub fn draw_text_opa(&mut self, pos: crate::geometry::Point, font: &'static embedded_graphics::mono_font::MonoFont, s: &str, c: Color, opa: u8, clip: Rect) {
        use embedded_graphics::draw_target::DrawTarget;
        use embedded_graphics::Drawable;
        struct EgTarget<'a, 'b> {
            d: &'a mut DrawBuf<'b>,
            c: Color,
            opa: u8,
        }
        impl DrawTarget for EgTarget<'_, '_> {
            type Color = embedded_graphics::pixelcolor::BinaryColor;
            type Error = core::convert::Infallible;
            fn draw_iter<I>(&mut self, pixels: I) -> Result<(), Self::Error>
            where
                I: IntoIterator<Item = embedded_graphics::Pixel<Self::Color>>,
            {
                for embedded_graphics::Pixel(p, col) in pixels {
                    if col == embedded_graphics::pixelcolor::BinaryColor::On {
                        self.d.put(p.x, p.y, self.c, self.opa);
                    }
                }
                Ok(())
            }
        }
        let style = embedded_graphics::mono_font::MonoTextStyle::new(font, embedded_graphics::pixelcolor::BinaryColor::On);
        let mut t = EgTarget { d: self, c, opa };
        let mut t = embedded_graphics::draw_target::DrawTargetExt::clipped(&mut t, &eg_rect(clip));
        let _ = embedded_graphics::text::Text::with_baseline(
            s,
            embedded_graphics::geometry::Point::new(pos.x, pos.y),
            style,
            embedded_graphics::text::Baseline::Top,
        )
        .draw(&mut t);
    }
```

辅助(文件内私有):`fn eg_rect(r: Rect) -> embedded_graphics::primitives::Rectangle`(x/y 起点 + 尺寸;负尺寸防御)。`put` 当前是私有方法(draw.rs:86),改为 `pub(crate)`。`Text::with_baseline` 若 0.8 实际签名不同(构造/baseline 设置方式),以文档为准调整并记录——语义由 Step 6 的像素测试钉住(pos = 字形盒左上角)。

- [ ] **Step 7: 新建 tests/font.rs(钉住语义)**

```rust
use embedded_graphics::mono_font::ascii::{FONT_6X10, FONT_10X20};
use qingui::draw::DrawBuf;
use qingui::font::{advance, line_height, text_size};
use qingui::{Color, Rect, Point, Ui};

#[test]
fn text_size_monospace_metrics() {
    let (w, h) = text_size(&FONT_6X10, "abc");
    assert_eq!(h, 10);
    assert_eq!(w, 3 * advance(&FONT_6X10) - FONT_6X10.character_spacing as i32); // 末字不计字距
    let (_, h2) = text_size(&FONT_6X10, "a\nb");
    assert_eq!(h2, 20);
    assert_eq!(line_height(&FONT_10X20), 20);
}

#[test]
fn draw_text_origin_is_top_left() {
    // 'A' 在 FONT_6X10 的字形盒左上角区域应有 On 像素,且不超过 character_size 盒
    let mut buf = [Color::BLACK; 64];
    {
        let mut d = DrawBuf { pixels: &mut buf, area: Rect::new(0, 0, 8, 8), stride: 8 };
        d.draw_text(Point { x: 0, y: 0 }, &FONT_6X10, "A", Color::WHITE, Rect::new(0, 0, 8, 8));
    }
    let on = |x: usize, y: usize| buf[y * 8 + x] == Color::WHITE;
    assert!(buf.iter().any(|&p| p == Color::WHITE)); // 画出了东西
    // 字形盒外(右侧 spacing 区与行高以下)无像素
    for x in 6..8 {
        for y in 0..8 {
            assert!(!on(x, y), "spacing 区不应有像素");
        }
    }
}

#[test]
fn default_font_and_override() {
    let mut ui = Ui::new(64, 64, 16);
    let s = ui.screen();
    let l = qingui::widgets::label::LabelBuilder::new("hi").build(&mut ui, s);
    assert!(core::ptr::eq(ui.resolved_style(l).font, &FONT_6X10));
    // 全局默认可换
    ui.set_default_font(&FONT_10X20);
    assert!(core::ptr::eq(ui.resolved_style(l).font, &FONT_10X20));
    // style.font 覆盖全局默认
    let mut st = qingui::style::Style::default();
    st.font = Some(&FONT_6X10);
    ui.set_style(l, st);
    assert!(core::ptr::eq(ui.resolved_style(l).font, &FONT_6X10));
}
```
